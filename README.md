## The entry

> I counted 14 door openings today. Zero meals taken. The leftovers expired Tuesday. I'm keeping them as evidence.

112 characters, one line. The fridge is smug about its sensors — it counted every door opening — petty about the owner's habit of opening it and taking nothing, and ends on a sting: the expired leftovers aren't trash, they're evidence. Small, domestic, and exactly the note a fridge would keep on its door screen.

## Run it

```sh
node main.ts
```

Writes the entry to `/output/entry.txt` and verifies it: 1–200 characters, exactly one line, no trailing newline, clean UTF-8, not whitespace-only. Deterministic — the same fixed text on every run. Node.js 22, standard library only, no network, no randomness, no clock.
